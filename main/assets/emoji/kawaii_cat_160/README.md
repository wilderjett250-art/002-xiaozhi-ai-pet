Kawaii Cat Emoji Collection

This collection contains original PNG assets generated for the local XiaoZhi
desktop-pet firmware build. The images are mapped to the standard XiaoZhi
emotion names and sized at 160 x 160 pixels for the 240 x 240 ST7789 screen.

Primary emotions:
- neutral
- happy
- laughing
- funny
- loving
- confident
- kissy
- surprised
- sad
- angry

Additional aliases are included for firmware states such as sleepy, thinking,
confused, shocked, crying, relaxed, and microchip_ai.
